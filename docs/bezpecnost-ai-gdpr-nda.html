AI v marketingu: Bezpečnost, GDPR a NDA

Oficiální přehled pro klienty a specialisty. Jak bezpečně pracovat s AI v agenturním prostředí podle typu licencí a účtů.

💡 Jak funguje trénování modelů a ochrana dat podle licencí?

Existuje zásadní rozdíl mezi vývojářským API / firemním účtem (Workspace) a běžným osobním předplatným. Zatímco vývojářská API a firemní tarify mají trénování zakázáno přímo v obchodních podmínkách, u běžného předplatného pro osobní účty (Google One AI Premium / ChatGPT Plus) je nutné trénování zkontrolovat v nastavení soukromí účtu.

🧠

1. Trénování podle typu účtu

Pro vývojáře (API) a firmy (Google Workspace) platí 0 % trénování. U osobního předplatného záleží na nastavení účtu.

🛡️

2. Pohled GDPR

PPC data (výkony, útraty, reklamy, URL produktů) neobsahují osobní údaje nakupujících zákazníků. Analýza je z pohledu GDPR čistá.

📜

3. NDA a mlčenlivost

Obchodní data jsou chráněna šifrováním (TLS 1.3 / AES-256). U striktních NDA smluv zakazujících cloud lze název značky anonymizovat.

⚖️ Závazné právní podmínky poskytovatelů (ToS)

1. Google Cloud / Gemini API (Data Processing Addendum)

"Google does not use Customer Data to train Google Cloud AI models without prior permission."

Zdroj: Google Cloud DPA (cloud.google.com/terms/data-processing-addendum)

2. Anthropic — API klíč z Console, Team, Enterprise (Commercial Terms of Service)

"Anthropic will not use Customer Data (including Prompts and Outputs) to train our models."

Zdroj: Anthropic Commercial Terms (anthropic.com/legal/commercial-terms, sekce 3.3). Neplatí pro přihlášení tarifem Free / Pro / Max — ten běží pod spotřebitelskými podmínkami i v Claude Code v terminálu. Detail: docs/nda-rezim.md.

3. OpenAI API & Enterprise (Business Terms)

"OpenAI does not use data submitted by customers to our API to train OpenAI models."

Zdroj: OpenAI Enterprise Privacy (openai.com/enterprise-privacy)

✅ Pravidla pro bezpečnou práci s AI v agentuře

  • Vývojářská API a Firemní účty: Pro klientská data používejte vývojářská API nebo firemní účty (Google Workspace / ChatGPT Enterprise), které mají trénování garantovaně vypnuté.
  • Osobní předplatné zkontrolujte v nastavení: Pokud používáte osobní předplatné (Google One AI Premium / ChatGPT Plus), vypněte v nastavení účtu ukládání historie a trénování modelů.
  • Přístupy a tokeny v oddělených souborech: API klíče a hesla uchovávejte v souboru .env. Neposílejte je do chatu.
  • Anonymizace u striktních NDA: Pokud smlouva s klientem zakazuje cloudové služby 3. stran, nahraďte jméno klienta obecným označením (např. Eshop_Elektro).
